# REQ-2297: Add ExcludeFromCodeCoverage attribute to generated code.

Source: https://github.com/MessagePack-CSharp/MessagePack-CSharp/issues/2297
Type: feature

## Requirement

MessagePack generated code is not decorated with the `ExcludeFromCodeCoverage` attribute. Because it is very hard to write good coverage for generated MessagePack code, it may skew coverage numbers, especially on large projects with a lot of generated code.

Solution requested: "I would like all generated code to be decorated with ExcludeFromCodeCoverage attribute.  I do not feel like a setting is needed, but setting would be fine to have too."

Alternatives considered by the author: none; "it is close to impossible to write good coverage for generated code as it covers many edge cases."

## Acceptance criteria

- All generated code is decorated with `ExcludeFromCodeCoverage`.
- No new setting or option is required to get the attribute. ("I do not feel like a setting is needed")
- An opt-out setting would be acceptable but is optional. ("setting would be fine to have too")
- The generated code still compiles on every supported target framework (the attribute must exist there or be conditionally emitted). (derived)
- Existing verified generator snapshots are updated to include the attribute. (derived)
