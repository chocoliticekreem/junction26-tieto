# REQ-2234: The analyzer does not work if SuppressSourceGeneration = true

Source: https://github.com/MessagePack-CSharp/MessagePack-CSharp/issues/2234
Type: bug

## Requirement

The analyzer does not work if `SuppressSourceGeneration = true`. This has happened since version 3.1.1. It still worked in 3.1.0.

(The upstream issue contains no further text, repro or comments. Anything beyond this is derived.)

## Acceptance criteria

- With `SuppressSourceGeneration = true`, the MessagePack analyzer still reports its diagnostics (MsgPack0xx rules) for code that violates them. (derived)
- Behaviour with `SuppressSourceGeneration = true` matches version 3.1.0, where the analyzer worked. (derived)
- Behaviour with `SuppressSourceGeneration` unset or false does not change. (derived)
- Source generation itself stays suppressed when `SuppressSourceGeneration = true`. (derived)
